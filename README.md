This is a Visual Studio Community edition 22 project. It generates an N-level Quasi-geostrophic channel model. The generated EXE runs only on Windows. The project uses Win32-APIs for the UI and display of graphics and is  written in Intel Fortran. The number of levels and the horizontal resolution is arbitrary and is specified by the user and is limited only by the resources on your PC. The model supports the use of interaction coeffcients or spectral transforms. If the horizontal resolution requires more than a certain number of interaction coefficients the integration method will automatically switch to the use of transforms.

The model has a default configuration.

This model represents ongoing work and not all features are currently implemented even though there is a UI suggesting that might be the case.
