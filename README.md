This is a Windows win32-based intel fortran N-level Quasi-geostrophic channel model. The number of levels and the horizontal resolution are arbitrary and limited only by the resource on your PC.
The UI and display of maps, Hovmoller diagrams, cross sections, phase space and time series plots are all done using the win32 API. The modell supports the use of interaction coeffcients or
spectral transforms. If the horizontal resolution requires more than a certain number of interaction coefficients the integration method will automatically switch to the use of transforms.

This model represents ongoing work and not all features are currently implemented.
